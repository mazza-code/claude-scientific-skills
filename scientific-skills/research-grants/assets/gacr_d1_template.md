# GACR STD 2027 Part D1 Template (Applicant/Co-applicant CV)

Use this template for `GACR_STD_2027` Part D1.

Hard constraints:

- Language: English
- File type: PDF (uploaded separately in GRIS)
- Max file size: 1 MB
- Max length:
  - Applicant: 2 A4 pages
  - Plus up to 2 A4 pages for each co-applicant
- Font and spacing: 11 pt, single spacing

---

## D1 Document Structure

### A. Applicant CV (max 2 pages)

#### A1. Identification
- Name
- Current position and institution
- Contact details (if required by local process)

#### A2. Structured Professional Profile
- Current role and core expertise
- Career trajectory summary
- Major methodological/disciplinary strengths relevant to this proposal

#### A3. Activities In The Project Field (Last 5 Years)
- Targeted list of activities directly relevant to proposed project topic:
  - research activities
  - leadership activities
  - collaboration activities
  - mentoring/training activities

#### A4. Optional Career Gap/Productivity Context (If Needed)
- Brief, factual explanation of career breaks or productivity disruptions.

---

### B. Co-applicant CV Blocks (up to 2 pages per co-applicant)

Repeat a compact version of A1-A4 for each co-applicant:

- Name and role in project
- Structured professional profile
- Last-5-years activities in project field
- Optional career gap context

---

## Recommended Compression Strategy (To Stay Within Limits)

- Keep each entry evidence-based and role-specific.
- Use compact bullet format with no narrative repetition.
- Prioritize relevance to current project over full historical detail.
- Move extended track-record details to D2 (not D1).

---

## D1 Final Compliance Gate

- [ ] Entire document in English
- [ ] Applicant block <= 2 pages
- [ ] Each co-applicant block <= 2 pages
- [ ] Total PDF <= 1 MB
- [ ] 11 pt, single spacing
- [ ] Content restricted to CV scope (no extra annex material)
