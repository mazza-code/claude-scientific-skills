# GACR STD 2027 Pre-Submission Checklist

Use this as the final hard gate for `GACR_STD_2027`.

## 1. Proposal Identity And Scope

- [ ] Correct call profile selected (`GACR_STD_2027`)
- [ ] Project title is clear, specific, and within format requirements
- [ ] Evaluation panel selection is coherent with project scope
- [ ] Interdisciplinary designation used only when justified

## 2. Language And Completeness

- [ ] Entire proposal is in English
- [ ] All required parts present: A, B, C1, C2, D1, D2, E
- [ ] No missing required data fields in forms

## 3. Hard File Constraints

- [ ] C1 uploaded as PDF
- [ ] C1 <= 10 pages A4, 11 pt, single spacing
- [ ] C1 file size <= 6 MB
- [ ] D1 uploaded as PDF
- [ ] D1 page limits respected (2 pages applicant + up to 2 per co-applicant)
- [ ] D1 file size <= 1 MB

## 4. Formal Correctness

- [ ] All identifiers and organization details are correct
- [ ] Required citations are provided for borrowed text/ideas
- [ ] No contradictory data across parts
- [ ] No clearly false or unsupported statements

## 5. Part A Constraints

- [ ] Abstract <= 1,100 characters (including spaces)
- [ ] Scientific aim <= 300 characters (including spaces)
- [ ] Keywords and classification fields completed as required

## 6. Part B Financial Syntax And Logic

- [ ] Financial entries rounded to nearest thousand CZK where required
- [ ] Cost totals and subtotals are internally consistent
- [ ] Funding proportions are mathematically consistent
- [ ] Each cost item is explicitly justified

## 7. Personnel/FTE Compliance

- [ ] No zero FTE entries
- [ ] Applicant and co-applicant workloads are realistic
- [ ] Cumulative GACR workload per person does not exceed 1.00
- [ ] Salary support respects cap (CZK 65,000/month prorated by FTE)
- [ ] Work-agreement compensation respects cap (CZK 400/hour)
- [ ] No planned milestone-bonus style personnel costing

## 8. Investment/Overhead Compliance

- [ ] Investment share respects call cap logic (10% limit condition)
- [ ] Overheads respect cap logic (20% limit condition)
- [ ] If overhead not requested now, note that it cannot be added later
- [ ] High-value procurement thresholds addressed with required quote package

## 9. C1 Scientific Quality Risk Gate

- [ ] Clear knowledge gap is defined
- [ ] Hypothesis/research question and verification method are explicit
- [ ] Methodology is appropriate for hypothesis testing
- [ ] Aims and outputs are feasible within timeline and resources
- [ ] Risks and mitigation are explicit
- [ ] Team roles/FTE in C1 align with Part B

## 10. Part E And Overlap Disclosures

- [ ] All required current/past/applied projects are disclosed
- [ ] Role, FTE, funding, and relationship-to-proposal fields completed
- [ ] No apparent undisclosed overlap with similar projects

## 11. Annex Discipline

- [ ] Only permitted annex categories are included
- [ ] No extra attachments beyond tender-allowed list

## 12. Final Operational Checks

- [ ] Submission package prepared through GRIS workflow
- [ ] Correct submission channel selected
- [ ] FINAL version verified before send
- [ ] Internal institutional review completed
- [ ] Compliance status recorded (pass/fail with fixes)
