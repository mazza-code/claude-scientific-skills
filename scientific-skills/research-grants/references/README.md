# Research Grants References

## Scope

This references bundle supports grant writing across:

- NSF
- NIH
- DOE
- DARPA
- NSTC (Taiwan)
- GACR (Czech Science Foundation)

It is designed for agency-specific drafting, review-criteria alignment, and formal-compliance checks.

- `nih_guidelines.md`

- `gacr_guidelines.md`

### Cross-Cutting Guides

- `broader_impacts.md`
- `specific_aims_guide.md`

## GACR Usage Model

For Czech proposals, always use two layers:

1. Agency track: `GACR` (`gacr_guidelines.md`)
2. Call profile: exact tender profile (`gacr_std_2027_guidelines.md` for this repository)

Do not finalize text without passing call-profile compliance checks (format, language, budget/FTE, annex rules).

## Recommended Workflow

1. Select agency + call profile.
2. Load the relevant agency guide and (if applicable) call profile.
3. Draft requested sections using corresponding asset template.
4. Run a formal compliance check before finalizing.
